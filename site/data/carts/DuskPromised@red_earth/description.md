# Pokémon Red Earth

A curated Pokémon Red cart combining a voxel presentation, all 151 obtainable in one save, Wilds of Kanto, shiny Pokémon, modern UI/storage/bag tools, quality-of-life upgrades, Kanto achievements, and the FAFF0x quest/story layer.

**Overworld Wild Encounters is intentionally not included. Wilds of Kanto is the sole overworld wild system.**

The cart uses `sealed+`, so the pinned set and load order stay defined while individual pinned mods can still be toggled on or off.
